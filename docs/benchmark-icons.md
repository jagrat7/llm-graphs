# Benchmark icons

Every registered benchmark has an official source mark in `SourceLogo`. Images are stored locally under `public/benchmarks`; no remote image requests are needed at runtime. Decorative icons have empty alternative text / `aria-hidden`, with the benchmark name displayed beside them.

Colored marks keep their official colours in every state, including rest, hover, focus, and selection. Define monochrome marks with `brand: { light, dark }` in `SourceLogo`; their default rendering uses those theme variants. Provider tooltips pass `monochromeColor="inherit"` so every monochrome mark, including future additions, follows the tooltip text color automatically. Colored marks and image assets retain their brand colors. An exhaustive `Record<ProviderName, SourceMark>` makes a missing icon for a new provider a type error. All marks remain trademarks of their owners.

Verified in the collaborative browser at 1280×800 and 390×844: all eleven menu icons loaded at 12×12, light and dark themes rendered them, the images displayed their original colours at rest and when selected, and the mobile page had no horizontal overflow. The existing 115 tests, typecheck, lint, format check, and production build passed.
